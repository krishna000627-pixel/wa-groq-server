ARIA NATIVE UI V3
==================

Replace the repository's dashboard.html with this file.

Termux:
  cd ~/wa-groq-server
  unzip -o ~/Downloads/aria_native_ui_v3.zip
  git add dashboard.html
  git commit -m "feat: replicate Aria native mobile UI"
  git push

This package changes the dashboard UI only. Backend endpoints remain on the existing server.
